## Usage Notes

This general context serves as the foundation for all platform-specific content. When creating posts for LinkedIn or Twitter, always start here for:

1. **Mission alignment** - Does this content serve your overall goals?
2. **Voice consistency** - Does this match your core principles?
3. **Audience relevance** - Does this address your target audience's needs?
4. **Research backing** - Do you have data/trends to support this?

Then apply platform-specific guidelines for formatting, tone, and distribution strategy.
