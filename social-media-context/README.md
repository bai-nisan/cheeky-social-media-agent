# Social Media Context Organization

This directory contains all context needed for AI-powered social media content creation and engagement across LinkedIn and Twitter.

## Structure Overview

### 📋 `/general-context/` - Cross-Platform Knowledge
Universal context that applies to both LinkedIn and Twitter:
- Mission, goals, and audience
- Core voice and expertise areas  
- People and accounts (cross-platform)
- Content research and industry trends
- Engineering systems and automation

### 🐦 `/twitter-specific/` - Twitter-Only Context
Context specific to Twitter/X platform:
- All your tweets and reply examples
- Twitter creation guidelines and voice
- Twitter engagement strategy
- Twitter technical setup and automation

### 💼 `/linkedin-specific/` - LinkedIn-Only Context  
Context specific to LinkedIn platform:
- All your LinkedIn posts (Hebrew/English)
- LinkedIn creation guidelines and voice
- LinkedIn engagement strategy
- LinkedIn technical setup and automation

## Usage Philosophy

When creating content:
1. **Start with general-context** for mission, voice, and research
2. **Apply platform-specific guidelines** for format and style
3. **Reference platform-specific examples** for tone and structure
4. **Use platform-specific engagement strategy** for distribution

## Content Creation Workflow

```
General Mission + Voice → Platform Guidelines → Platform Examples → Content Creation
```

This structure ensures consistency across platforms while optimizing for each platform's unique characteristics and audience expectations.
