## Automated Discovery-Reply Workflow (Cursor)

> New workflow added 2025-07-29
>
> As requested, we now surface fresh, relevant tweets directly inside Cursor and draft high-value replies without leaving the editor.

### How It Works
1. **Run helper script**  
   ```bash
   npx tsx scripts/search-tweets.ts "<query>"
   ```
   • Uses your **TWITTER_BEARER_TOKEN** to pull the 10 most recent tweets for any keyword or hashtag (e.g. `"AI startup"`, `"#buildinpublic"`).  
   • Output includes a link + trimmed text for quick scanning.
2. **Select opportunities**  
   • We (ChatGPT + you) pick 1-2 tweets where a thoughtful comment can add value & attract your target audience.
3. **Reply drafting**  
   • Inside Cursor, I generate concise, insight-rich replies.  
   • You copy-paste to X (or schedule via Typefully once added).
4. **Log insight**  
   • Any pain-point or idea that surfaces goes into the *Idea Vault* for future original content.

### When To Use
| Frequency | Purpose |
|-----------|---------|
| **Daily (Mon-Fri)** | Find 1 tweet for quick engagement (10-min block of Micro-Routine). |
| **Thread Days (Wed)** | Source stat/quote hooks for the weekly thread. |
| **Launch Weeks** | Track launch-related keywords and jump into live conversations. |

### Rate-Limit Tips
* Free tier = 1 request / 15 min—limit searches to one or batch queries.
* Use broad terms first (`"AI startup"`), then narrow (`"agentic AI"`) if results feel off.
